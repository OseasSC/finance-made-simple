# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-28

### Added

- Single-page finance planner with black and Solo Leveling–inspired purple theme.
- Photo upload for bank balance, extrato, and bills with OpenAI Vision extraction via `/api/extract`.
- Review step before committing extracted data to local storage.
- Editable planilha (transactions table) with sortable columns.
- Charts: expenses by category, income vs expenses, balance trend.
- Rule-based savings plan (50/30/20 guidance, top categories, weekly checkpoints).
- PDF export with planilha, savings steps, and category chart snapshot.
- `docs/VERSIONING.md` describing SemVer, storage schema, API contract, and release process.
